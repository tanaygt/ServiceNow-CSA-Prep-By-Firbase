# ServiceNow Certification Hub

A full-stack educational platform for ServiceNow CSA & CAD certification preparation.

## Features
- Learning Dashboard with progress tracking
- Study Resources integration
- Interactive flashcards and quizzes
- AI-powered mentor chatbot
- Career guidance section

## Tech Stack
- Frontend: React + Tailwind CSS
- Backend: Firebase Functions
- Database: Firestore
- Authentication: Firebase Auth
- AI: Google Generative AI

## Setup
1. Clone repository
2. Install dependencies: `npm install`
3. Configure Firebase
4. Start development: `npm start`
