# **App Name**: ServiceNow Prep

## Core Features:

- Module Access: Users can access learning modules.
- Progress Tracking: Tracks user's progress through learning modules.
- AI Chat Mentor: An AI mentor is available to answer questions related to course content. The AI tool will use the project description to guide the responses it provides.
- Quiz System: Presents quizzes to users and provides instant feedback.
- Flashcard System: Provides flashcards to help users memorize key concepts.
- User Authentication: Secure user authentication via Firebase.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and professionalism.
- Background color: Very light blue (#E8EAF6) for a clean and calming effect.
- Accent color: Orange (#FF9800) for calls to action, providing a sense of energy.
- Body and headline font: 'PT Sans', sans-serif, combining modernity and a touch of warmth.
- Code font: 'Source Code Pro' for displaying code snippets.
- Use flat, modern icons to represent different modules and features.
- Clean and structured layout for easy navigation and readability.
